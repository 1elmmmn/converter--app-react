# Курс: конвертер валют (React + TypeScript)

![CI](../../actions/workflows/ci.yml/badge.svg)

Веб-приложение для конвертации валют по официальным курсам Центрального банка РФ. React 19, TypeScript и Vite; график курса нарисован на чистом SVG без библиотек.

**Демо:** _вставьте ссылку на GitHub Pages_

## Возможности

- Мгновенная конвертация при вводе, любые пары валют ЦБ РФ (кросс-курс считается через рубль, номинал учитывается: ЦБ публикует иену за 100 единиц, и курс считается за одну)
- Умный разбор суммы: `1 000,50`, `1,000.50`, `1000.5`, с пробелами и неразрывными пробелами
- Валидация с понятными сообщениями об ошибках (`aria-invalid`, `role="alert"`)
- Кнопка «поменять местами», быстрые пары, история последних конвертаций (повтор в один клик)
- График курса за 14 дней: наведите курсор, чтобы увидеть значение на любую дату; изменение за период в процентах
- Три уровня надёжности данных: ЦБ РФ → запасной API → последние сохранённые курсы; таймаут у каждого запроса
- Светлая и тёмная тема (учитывает системную настройку, выбор запоминается)
- Адаптивная вёрстка и доступность: подписи полей, фокус с клавиатуры, `aria-live` для результата, `prefers-reduced-motion`

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # тесты (Vitest + Testing Library)
npm run lint       # ESLint
npm run build      # проверка типов и сборка в dist/index.html
```

`npm run build` создаёт **один самодостаточный файл** `dist/index.html` (JS и CSS встроены). Его можно открыть двойным кликом (нужен интернет для курсов) или выложить на любой хостинг.

## Стек

React 19 (хуки, без классов), TypeScript в строгом режиме (`strict`, `noUncheckedIndexedAccess`), Vite, Vitest + React Testing Library + user-event, ESLint (включая правила хуков), GitHub Actions (CI и деплой на GitHub Pages).

## Структура

```
src/
  App.tsx                     состояние страницы и компоновка
  types.ts                    доменные типы
  components/
    CurrencySelect.tsx        выбор валюты (популярные сверху)
    QuickPairs.tsx            быстрые пары
    RateChart.tsx             график на SVG, подсказка при наведении
    ConversionHistory.tsx     история конвертаций
    Header.tsx                шапка и переключатель темы
  hooks/
    useRates.ts               загрузка курсов, отмена запросов при уходе со страницы
    useRateHistory.ts         курсы за последние дни (по ссылкам PreviousURL)
    useTheme.ts               тема: системная или выбранная вручную
    useLocalStorage.ts        состояние, которое сохраняется
    useElementWidth.ts        ширина блока для графика (ResizeObserver)
  lib/
    converter.ts              парсинг ответов, конвертация, форматирование (чистые функции)
    api.ts                    fetch с таймаутом и отменой, цепочка источников
    parse.ts                  проверка данных из localStorage
    format.ts, storage.ts
```

## Технические решения

- **Разделение логики и интерфейса.** Вся математика и разбор данных лежат в `lib/converter.ts` и не зависят ни от React, ни от браузера.
- **Устойчивость к сбоям.** Таймаут запросов и отмена через `AbortController`, цепочка источников, сохранённые курсы с проверкой формы данных. Если запрос отменён (пользователь ушёл со страницы), цепочка не переходит к следующему источнику.
- **Недоверенные данные.** Ответы API и содержимое `localStorage` проверяются на форму перед использованием; значения выводятся в DOM как текст, а не как HTML.
- **История курса без гонок.** Результат загрузки привязан к тем курсам, для которых он получен, поэтому устаревший ответ не показывается.
- **Деньги и форматирование.** Вывод через `Intl.NumberFormat('ru-RU')`; для сумм меньше единицы показываются значимые цифры, чтобы курс вроде `0,0125` не округлялся до нуля.

## Источники данных

- [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/): ежедневные курсы ЦБ РФ в JSON
- [open.er-api.com](https://open.er-api.com/): запасной источник

Курсы носят справочный характер.

## Тесты

38 тестов: конвертация и номинал, разбор сумм, проверка данных из хранилища, цепочка источников и отмена запросов, интерфейс (ввод, ошибки, быстрые пары, график, история, тема, режим без сети).

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий (папки `node_modules` и `dist` загружать не нужно, они в `.gitignore`).
2. Settings → Pages → **Source: GitHub Actions**.
3. После `git push` в ветку `main` workflow `deploy.yml` прогонит тесты, соберёт проект и опубликует его.
